## Suggested learning sequence

1. Start with the national motivation and modeling/simulation value chain.
2. Learn the major modeling paradigms.
3. Understand HPC hardware and parallel-computing concepts.
4. Learn the scientific software stack, modules, and Slurm execution.
5. Study the software ecosystems and application-specific parallelism.
6. Follow the GROMACS molecular-dynamics workflow.
7. Finish with profiling, optimization, benchmarking, scaling, and collaborative scientific computing.
