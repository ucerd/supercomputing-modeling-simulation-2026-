## Upload guidance

The seven PDFs are approximately 38 MB in total and each file is well below GitHub's 100 MB per-file hard limit, so Git LFS is not required for the current lecture set.

## Recommended branch protection

For a small public educational repository:
- use `main` as the default branch;
- require pull requests for changes to published lecture metadata if multiple maintainers are active;
- avoid force-pushes to `main`;
- use GitHub Releases for versioned archival snapshots.

## Before publishing

- Confirm presenter names and affiliations.
- Confirm public-distribution permission for every lecture.
- Review third-party images/logos and attributions.
- Keep the existing PDF content unchanged unless a presenter authorizes edits.
- Verify all PDF links in `README.md`.
- Verify `CITATION.cff` renders correctly in GitHub.
- Add a repository contact/maintainer.
