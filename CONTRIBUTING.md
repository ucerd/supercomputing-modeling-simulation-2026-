# Contributing

This repository primarily archives teaching material from the August 2026 Summer School on Supercomputing for Modeling and Simulation.

Contributions are welcome when they improve accuracy, reproducibility, or usability.

## Appropriate contributions

- correcting typographical or factual errors;
- improving lecture metadata;
- adding missing citations or attributions;
- adding reproducible hands-on examples;
- adding Slurm scripts, input files, or environment information;
- fixing broken links;
- documenting software-version compatibility.

## Before submitting a change

1. Do not modify a presenter's PDF without authorization.
2. For corrections to a PDF, open an issue describing the page and proposed correction.
3. Keep scientific results reproducible: provide software versions, inputs, resource requests, and logs where relevant.
4. Do not add copyrighted third-party material without permission or a valid legal basis.
5. Do not include passwords, access tokens, private cluster addresses, personal data, or institutional credentials.

## Pull requests

Use a concise title and explain:
- what changed;
- why it changed;
- which lecture or practical it affects;
- how it was verified.

For performance-related changes, include the baseline and the changed configuration so the comparison remains meaningful.
